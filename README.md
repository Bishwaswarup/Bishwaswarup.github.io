# bishwaswarup.github.io

Personal site of **Bishwaswarup Nayak** (BS Research, Physics, IISc Bengaluru): spacecraft GNC,
state estimation, cislunar space domain awareness, solar-sail dynamics and quadruped swarms.

The site is an explorable 3D solar system (React Three Fiber):

- **Star**: me. Click it for the CV dossier.
- **Planets**: projects, on inclined Keplerian orbits (periods follow Kepler's third law).
  Inner orbits have papers, middle orbits are research code, an asteroid belt, then apps and tools.
  Inclination shows how far a project sits from astrodynamics/GNC.
- **Rings**: the project has a paper or preprint.
- **Moons**: findings and features; bigger moon = more important result.
- **Satellites**: links to papers, archives and code.

Live at **https://bishwaswarup.github.io/**. See [SETUP.md](SETUP.md) to run or edit it.
